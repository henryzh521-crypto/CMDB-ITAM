# 智算资产管理平台 v3.5.1 升级说明

v3.5.1 是**质量强化补丁版**：修复 v3.5.0 全系统审查发现的 47 项缺陷与强化点（资产-财务删除边界、数据范围收口、SSE 慢消费者保护、监控告警行为一致性、仓库库存并发、前端 XSS 与竞态等）。
**无新功能、无数据库迁移（V46 仍为最新）、无新增必配项**，从 v3.5.0 直接升级。全部改动经 93 个自动化用例（9 个套件）回归通过，修复清单与结果见 `docs/TEST-REPORT-3.5.1.md`。

> 从 v3.4.x 及更早版本升级的，请先按 `docs/UPGRADE-3.5.md` 升级到 v3.5.0，再升 v3.5.1（SSE 反代配置等注意事项见该文档第一节）。

---

## 一、升级步骤

### Docker 部署

```bash
# 在旧安装目录
./dcimctl backup                                   # 先手工备份一次
./dcimctl upgrade /path/to/dcim-system-3.5.1     # 复制 .env/证书 → 自动备份 → 构建 → 启动
```

- 无数据库迁移，启动即完成。
- `.env` 会被沿用；唯一默认值变化见第二节 `WEBHOOK_BLOCK_LOCAL_SUBNETS`。

### 原生部署（systemd）

替换 `artifacts/` 后执行 `./install.sh --native`。启动脚本会在多个 jar 并存时选择**版本号最高**的一个。

### 升级后自检

```bash
ADMIN_PW='<admin口令>' EXPECT_VERSION=3.5.1 python3 tests/run_all.py -s smoke
```

界面右上角「关于本系统」应显示前后端版本 3.5.1。

## 二、行为变化（请通知用户）

| 变化 | 说明 |
|---|---|
| 资产删除守卫 | 被未完结工单引用、或财务状态已进入折旧 / 减值 / 处置流程的资产，删除返回 409（须先处理工单 / 完成财务处置）；批量删除计入错误行不中断整批 |
| 导出与导入上限 | 资产导出上限 10000 行（超限提示缩小范围）；CSV 导入上限 10MB / 50000 行（前端同样预校验，超限不发请求） |
| 工单「撤销」 | 新增待处理工单撤销路径（待处理 → 已关闭），仅申请人或管理员可执行 |
| 附件冻结 | 「已完成」与「已关闭」同为终态，工单附件禁止上传**与删除** |
| SSE 帧最小化 | SSE 广播帧只携带刷新信号（频道 / 类型 / 对象号），业务正文由前端带权限调 REST 获取——前端行为不变，外部脚本如依赖旧帧正文需改调接口 |
| Webhook 默认值 ⚠ | `WEBHOOK_BLOCK_LOCAL_SUBNETS` 代码默认 false → **true**（禁止推送平台自身网段）。原生部署且 Webhook 目标与平台同网段（如企业内网 OA）的，需在 `.env` 显式设 `WEBHOOK_BLOCK_LOCAL_SUBNETS=false` 并确认接受风险 |
| 采集器路径收口 | `/api/v1/collector/**` 不再匿名放行（统一走 `/api/collector/**`，采集器不受影响） |
| 财务校验收紧 | 减值金额不可超过账面净值（400 提示上限）；手工计提期间不可晚于当前月 |
| 并发冲突 409 | 问题单并发流转、盘点任务定稿后迟到提交明细等并发冲突统一返回 409 提示刷新重试 |
| 前端 CSP | 前端容器 nginx 新增 Content-Security-Policy 响应头（script-src 'self'）；自维护 nginx 的请参照 `platform-web/nginx.conf` 合并 |

其余修复（TDengine 超时与子表碰撞、内存指标仓上限、机柜 U 位并发保护、IPAM 分配加锁、路由死循环、tooltip XSS 等）不改变正常操作路径下的可感知行为。

## 三、回滚

无 DDL、无新配置依赖：换回旧目录（或 `artifacts/` 换回旧 jar）即可回滚。
注意唯一默认值差异：回滚到 v3.5.0 后 `WEBHOOK_BLOCK_LOCAL_SUBNETS` 默认回到 false，曾显式配置的 `.env` 值不受影响。
